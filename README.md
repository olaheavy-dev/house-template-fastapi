# house-template-fastapi

The FastAPI layer of my Copier project templates. It adds a Python backend under `backend/` to a project generated from [house-template-base](https://github.com/olaheavy-dev/house-template-base): FastAPI, SQLAlchemy with PostgreSQL and pgvector, S3-compatible storage, and one budget-capped LangChain model gateway with LangSmith tracing and recorded responses for CI.

Work in progress: the layer arrives through reviewed pull requests.
